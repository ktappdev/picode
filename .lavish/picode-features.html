Core Features

🤝

Multi-Agent Coordination

Coordinator delegates work. Workers auto-detect role from name: builder-1 → builder, explorer-a → explorer. Generic workers for any name.

📬

Durable Envelope Messaging

Single message shape: Envelope with expects, re, urgency, deliverAfter. Requests tracked as debts. Nothing falls through the cracks.

⚙️

Worker Management

spawn_worker splits panes, launches pi, waits idle. Auto-reuses dead workers. cleanup_panes closes stale ones.

📝

Auto-Journaling

Per-picode journal with compaction. Stays readable automatically. Read other picodes' journals with picode_journal.

🚧

Barriers & Waiting

picode_wait blocks until replies arrive. Supports deadlines and injected messages on resolution. Arm inline with wait=true.

⏸️

Suspend & Resume

Picode goes On Hold. Inbox queues messages until picode_resume drains them.

💾

Pluggable Storage

Local filesystem by default — no broker, no services. Swap to Restate for durable wake-on-message.

🖥️

CLI Monitoring

picode-cli.mjs — list, status, watch, tail, send. Zero dependencies. Monitor from any terminal.

⚡

Slash Commands

/picode-status, /picode-list, /picode-send, /picode-journal. Human steering from inside pi.

Model Tools

Tool Purpose
picode_sendSend envelope to name, group, wildcard, or role. Supports expects, re, urgency, wait.
picode_waitWait for replies (barrier). Deadline + injected message on resolution.
picode_statusRead state, obligations, owed replies, barriers, journal.
picode_listList all threads in workspace.
picode_journalRead another picode's journal. Filter by tail or lookback.
picode_suspendMark On Hold. Inbox queues until resume.
picode_resumeResume and drain queued messages.
spawn_workerSplit pane, launch pi, wait idle. Auto-reuses idle workers.
cleanup_panesClose stale herdr worker panes. dry_run preview available.
picode_purgeDelete stale picode data directories. Safe — only removes no-debt threads.
